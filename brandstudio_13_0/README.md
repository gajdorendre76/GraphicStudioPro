# BrandStudio 13.0 – Arch Linux / niri

Hungarian nyelvű, offline brand identity- és kiadványeditor.

## Launch

Csomagold ki a ZIP-et, majd nyisd meg az `index.html` filet Chrome-ban.

## Újdonságok

- Images forgatása (-180° – +180°).
- Images átlátszósága (0–100%).
- Images vágása pageanként, százalékban.
- Aránytartó illesztés vagy keretkitöltés.
- Imagesettings restorea.
- Settings megőrzése JSON-saveben, visszavonásban és SVG-exportban.

## Korlátok

A imagevágás nem módosítja az eredeti raszteres imagefilet. Az SVG export nem PDF/X és nem végez ICC colorkonverziót. A helyi böngészőtárhelyről rendszeresen készíts JSON savet.
